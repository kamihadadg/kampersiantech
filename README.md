# همراه علوم (`hamrah-ulum`)

مثل n8n: **فقط Node** لازم است. پایتون لازم نیست.

- **محتوای درسی:** JSON (`data/shared-adds.json` + `guide.js` هر علم)
- **کاربر / رمز / تنظیمات:** SQLite (`data/app.sqlite`)

نیاز: **Node.js 22.5+** (برای SQLite داخلی)

## اجرا (والد — یک کلیک)

1. `tools\pack-for-parents.ps1` را اجرا کن → ZIP داخل `dist\`
2. ZIP را روی گوگل‌درایو / تلگرام بگذار و **لینک دانلود** بفرست
3. والد: Extract → دوبارکلیک `START.bat` → Yes  
   بار اول اگر Node نباشد خودش دانلود می‌کند (اینترنت لازم است).

یا روی همین سیستم:

```bash
npm start
```

مرورگر روی صفحهٔ ورود باز می‌شود. پورت پیش‌فرض **۸۰۸۰** است.

## دستورها

| دستور | کار |
|---|---|
| `npm start` | سرور خانه روی همه اینترفیس‌ها |
| `npm run assistant` | فقط همین سیستم |
| `hamrah-ulum --port 9000` | پورت پیشنهادی دلخواه |
